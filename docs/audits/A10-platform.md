## Summary
72 findings: no P0, 2 P1, 33 P2, 37 P3. 51 fixed, 5 partly fixed, 9 deferred, 5 dropped, 2 decided under the owner's delegation (A10-22, A10-33; Q29's period too, A10-46). By dimension: ops 12, performance 12, security 8, observability 8, frontend 7, tests 7, UI 6, database 5, backend 2, accessibility 2, worker 1, spec 1, docs 1 (a finding counted once, under its first dimension).

What changed:
- **Deploys and restores (P1):** a restore is no longer undone by the health timer two minutes later, which ran the new code on the old schema and could run jobs again (A10-1); `provision.sh` can no longer leave the shared server's nginx broken: every file is tested once and put back on a refusal, and CI runs `nginx -t` on the configuration (A10-2).
- **Health and alerts:** the health timer waits for a deploy, heals after two failed runs, never restarts the store for an API outage, and stops repeating one warning all day (A10-3, A10-55, A10-71); outages, a full disk, certificates and a missing or failed backup now reach the owner on Telegram from the server itself (A10-12, A10-13); the worker's alerts survive a database outage (A10-52), a stopped worker shows on the dashboard (A10-53), and a stuck USDT scan names its transfer (A10-40).
- **Graceful restarts:** live streams no longer hold the API's shutdown until PM2 kills it (A10-4); the worker gets 35 s to stop its jobs (A10-5, SIGKILL on every deploy before); tabs open across a deploy keep loading their chunks, and the panel and the store reload cleanly when one is gone (A10-6, A10-7).
- **Privacy and bans:** nginx keeps no query string or share token in its logs (A10-8), the store's Sentry events no longer carry tokens; a carrier address shared by many customers is no longer banned from every site after ten rate refusals, while a sustained flood still is (A10-10); the store's cached reads no longer share one counter anyone could exhaust (A10-36).
- **Speed:** page payloads (RSC) are compressed (A10-9, up to 93 KB before); the store's reads of the API give up after 8 s (A10-14); the badges read counts instead of the dashboard and every supplier tree each minute (A10-25); navigation preload (A10-19); indexes for five lookups and deletions (A10-42, A10-43); the level recomputation is bounded (A10-47).
- **Customer screens:** no 200 px jump of the home page for a customer without quick-buy cards (A10-15); a failed session read no longer shows a signed-in customer "sign in" (A10-17); Arabic error pages everywhere (A10-7, A10-60); share links readable as `noindex` by crawlers (A10-58) and one canonical address per game (A10-62).
- **Panel:** dialogs and sheets no longer lose typed text on Escape or a click beside them (A10-20); a page error stays inside the shell with a retry, and every crash reaches Sentry (A10-26, A10-27); each tab names its page (A10-28); 44 px touch targets on phones and row buttons named after their row (A10-23); the typed client without `as never` on JSON bodies (A10-21); network failures say so (A10-31).
- **Data rules in the database:** a USDT credit needs its bound transfer (A10-41), slugs never change, margin rules and the catalog are never deleted by the app role (A10-44); settled emails and Telegram messages lose their addresses and parameters after 90 days (A10-46, Q29).
